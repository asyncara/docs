---
title: "حدود الموارد وملكية الإلغاء"
---

ذاكرة PHP وذاكرة Asyncara الأصلية وتخصيصات المكتبات ومخازن kernel وعمليات الأبناء ميزانيات مختلفة. لا يوجد حد واحد يغطيها كلها.

```php
Asyncara\Runtime::configure([
    'taskLimit' => 10000, 'futureLimit' => 20000,
    'nativeMemoryLimit' => 128 * 1024 * 1024,
    'httpMaxConnections' => 64, 'httpMaxHostConnections' => 8,
]);
```

اضبط قبل بدء Scheduler. تجاوز السعة خطأ صريح وليس إسقاطاً صامتاً. Queue وstream يوقفان producer عند الامتلاء؛ pool يحد الاتصالات والمنتظرين؛ إشعارات قواعد البيانات محدودة وتفشل عند التجاوز. راقب الحدود وعدد العمليات المعلقة لا إجمالي عمليات عمر الخدمة.

Future::await(token) يلغي انتظار المستهلك فقط، بينما Async::await صيغة مالك تلغي وتجمع العملية غير المنتهية عند الخروج. إلغاء SQL لا يثبت توقف الخادم؛ إلغاء ملف لا يتراجع عن كتابة، وإلغاء HTTP لا يسحب بايتات أُرسلت.

الموارد عموماً تمنع clone/serialization؛ الإسناد يشترك بالكائن نفسه لا بمقبض مستقل. أغلق في finally وانتظر close غير المتزامن. SIGKILL وOOM وانهيار المضيف لا تضمن rollback أو cleanup تطبيقيًا.

اضبط memory_limit وحدود العملية والملفات والاتصالات وأجسام الطلبات معاً. كل worker يضاعف ميزانيته المستقلة. ledger لا يشمل كل libcurl/OpenSSL/libpq/SQLite. افحص الاتجاهات بعد الإحماء لا لقطة RSS واحدة.
