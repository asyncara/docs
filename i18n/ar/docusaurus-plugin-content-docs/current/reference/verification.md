---
title: "التحقق من الأمثلة"
---

نُفذت الأمثلة على Linux x86_64 وPHP8.5.12 NTS بالامتداد المنشور0.10.0. اجتازت epoll وpoll أمثلة Tasks وإلغاء المنتظر وQueue وSQLite والملفات والتدفقات وTCP، والخادم المحلي وHTTP بمحركَي curl وHyper.

اجتاز105 مقاطع PHP و12 ملفاً كاملاً فحص الصياغة. نجح ProcessPool مع runtime المصدر الكامل فقط؛ الحزمة الأولى تفتقد ملف العامل، لذلك لم يُدع نجاحها فيه.

النتائج المنقحة: [الحزمة](pathname:///docs/evidence/examples-bundle-r1.json) و[المصدر الكامل](pathname:///docs/evidence/examples-source-r1.json). تتضمن البصمة والفحوص الفعلية. هذه اختبارات أمثلة وليست endurance أو benchmark أو اعتماد بروتوكولات كامل. وصفات قواعد البيانات البعيدة وTLS/proxy ذات نطاق example.net تحتاج إعداداتك ولم تنفذ ضمن هذا الفحص.
